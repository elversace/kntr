# kntr — حزمة التطبيق الكاملة

## المحتويات
- `kntr-backend/` — سيرفر الـ API (Node.js + Express + PostgreSQL)
- `frontend/` — الواجهات الأربع (ملفات HTML مستقلة، تُفتح مباشرة بأي متصفح)

## تشغيل الـ Backend
```bash
cd kntr-backend
npm install
cp .env.example .env      # عدّل القيم (JWT_SECRET، بيانات قاعدة البيانات)
npm run db:create && npm run db:migrate
npm run dev
```
السيرفر يعمل افتراضياً على http://localhost:3000/v1

## فتح الواجهات
افتح أي ملف من مجلد frontend مباشرة بالمتصفح (دبل كليك أو من داخل المتصفح).
كل واجهة فيها حقل "عنوان الـ API" أعلى الصفحة — اضبطه على عنوان السيرفر الفعلي
(افتراضياً http://localhost:3000/v1، أو عنوان السيرفر لو رفعته على استضافة).

- kntr-app.html → **التطبيق الموحّد**: نفس الملف لكل من العميل والسائق —
  بعد تسجيل الدخول يتعرّف تلقائياً على نوع الحساب ويعرض الواجهة المناسبة
  (طلب جديد + تتبّع للعميل، أو استقبال طلبات + تسليم للسائق)
- kntr-admin-dashboard.html → لوحة تحكم الإدارة (أداة داخلية منفصلة)

## ملاحظة مهمة
هذه الواجهات صفحات ويب عادية (HTML/CSS/JS) تعمل داخل أي متصفح على أي جهاز —
وليست تطبيقات جوال أصلية من متجر التطبيقات (App Store / Google Play).
