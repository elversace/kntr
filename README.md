# KNTR

مشروع التوصيل: خادم Node.js وPostgreSQL، واجهة ويب، ومشروعا Android وiOS عبر Capacitor.

ابدأ من [تقرير تجهيز التشغيل](KNTR-STARTUP-AR.md) و[التجربة عبر GitHub Codespaces](CODESPACES-SETUP-AR.md). للتشغيل على استضافة لاحقًا راجع [إعداد Railway](kntr-package/kntr-backend/RAILWAY-SETUP-AR.md). جذر خدمة الخادم هو `kntr-package/kntr-backend`.

إصلاحات الصلاحيات والتسليم والمال والوثائق موثقة في [تقرير البنود 1–4](KNTR-FIXES-1-4-AR.md). الاختبارات ونتائجها في `verification`، وتعليمات إعادة تشغيلها في [دليل التحقق](verification/README.md).

تطبيقات الجوال تحتاج البناء واختبار الأجهزة واستكمال الموقع والإشعارات قبل اعتمادها للنشر. لا يحتوي المستودع على بيانات تشغيل حقيقية أو أسرار أو ملفات مستخدمين.
